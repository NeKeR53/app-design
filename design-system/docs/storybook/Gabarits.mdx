# Gabarits

Chaque élément de cette section est d'abord spécifié avec `/design define`, validé sur une page de validation, puis codé avec ses stories.

- **ChatPage** : page de chat avec un agent ; barre d'outils, relevé, pied aligné sur la colonne de 760 px, dépôt de fichiers sur toute la page (D-382).
- **ListPage** : page qui liste des éléments ; l'app décrit ses données, le gabarit dessine tout (D-173 à D-178).
