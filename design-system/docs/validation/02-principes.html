Étape 2 — Principes VALIDÉ le 2026-11-21

Le même écran de travail rendu selon trois directions. Toutes reprennent la structure de l'app desktop Claude. Elles ne diffèrent que par le ton : gris, rayons, densité, respiration.

Déjà décidé

  • Apps de travail web (bureau, tablette, mobile) et desktop Tauri.
  • Structure inspirée de l'app desktop Claude : sidebar repliable avec overlay, sections repliables, éléments imbriqués, en-tête minimaliste, panneau de détail.
  • Style neutre, avec une seule couleur d'accent configurable par app. Ici, un bleu de démonstration.
  • Mode clair et mode sombre.
  • D-001 : ton A, « sobre fidèle ».
  • D-002 : une section de sidebar peut contenir des éléments de navigation (section « Favoris ») ou des éléments sur deux lignes avec enfants (« À traiter », « En cours »).
  • D-003 : sur mobile, barre d'onglets en bas avec « Plus », qui ouvre le menu complet dans une feuille.
  • D-004 : deux densités, web confortable et desktop compact.
  • D-005 : le mode suit le système, avec un choix manuel dans les réglages.
  • D-006 : raccourcis « Mod » (⌘ sur macOS, Ctrl sur Windows), palette de commandes Mod+K.
  • D-007 : actions au survol, application immédiate, bonnes valeurs par défaut, confirmation seulement pour l'irréversible.
  • WCAG 2.2 AA. Français, composants prêts pour d'autres langues.

À décider

  1. Ton visuel : A retenu (D-001).
  2. Densité : deux densités (D-004).
  3. Mode par défaut : suivre le système (D-005).
  4. Navigation mobile : M1 retenue (D-003).
  5. Clavier / souris : raccourcis « Mod » et palette Mod+K (D-006).
  6. Réduction des clics : quatre règles (D-007).

À essayer dans chaque cadre : survolez le bouton de repli une fois la sidebar repliée, survolez « Documents » ou « Rapports » pour voir leur action, repliez une section, dépliez un élément, sélectionnez une ligne, puis naviguez avec Tab.

A — Sobre fidèle

Retenu — D-001

Au plus près de l'inspiration : gris légèrement chauds, rayons moyens (10 px), respiration confortable.

Pourquoi je le recommande : c'est la direction que vous avez décrite. Elle reste neutre, l'accent ne sert qu'à porter un sens, et elle tient bien dans les deux densités.

B — Compact technique

Écarté

Gris froids, petits rayons (6 px), espacements serrés : plus d'information visible par écran.

Pour des écrans très chargés (tableaux, journaux). Plus austère, et la densité « web » y est déjà assez serrée.

C — Doux aéré

Écarté

Fonds crème, grands rayons (14 px), plus d'air : plus chaleureux, moins d'information à l'écran.

Plus accueillant, mais moins adapté à la saisie intensive. Il demande plus de place sur mobile.
