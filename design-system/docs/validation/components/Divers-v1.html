    1. Disclosure — bloc repliable

    Besoin : « ▸ Blocs repliés » du panneau de droite d'Alfred. Générique : « Options avancées » d'un formulaire, détails d'une erreur, questions fréquentes. Recouvrement : Sidebar.Section et DetailPanel.Section sont des titres de section repliables ; Disclosure est un bloc dans une section ou dans un contenu. Les trois gardent le même titre.

    A — titre de section recommandée

    Même titre et même chevron que les sections (D-061). Une seule forme de repli dans le design system.

    Délai d'expiration, nombre d'essais, journal détaillé.

    B — chevron devant, titre plein

    Forme « ▸ titre » d'Alfred, titre en --fg. Deux formes de repli dans le même panneau.

    Délai d'expiration, nombre d'essais, journal détaillé.

    C — encadré

    Bloc avec bord, chevron à droite. Plus lourd ; ajoute un cadre dans un panneau déjà découpé par des traits.

    Délai d'expiration, nombre d'essais, journal détaillé.

    Comportement retenu : clic, Entrée ou Espace sur le titre ; replié par défaut ; contenu créé seulement à l'ouverture ; aucune animation (D-026) ; avec un id, l'état est mémorisé (comme D-061). Écarté : apparence subtle, className du titre, élément natif <details>.

    2. InlineEdit — texte modifiable sur place

    Besoin : titre et valeurs du panneau de détail (layout-rules : « propriétés modifiables sur place »). Générique : renommer un document, une liste, une vue. Essayez : clic ou Tab puis Entrée ; Entrée enregistre ; Échap annule ; clic à côté enregistre. « Plusieurs lignes » : Entrée passe à la ligne, Mod+Entrée enregistre. Bascule « Enregistrement » : attente et échec.

    3. StepList — étapes numérotées

    Besoin : parcours d'installation ou de configuration. Quatre états : à faire, en cours, fait, erreur. Une étape faite (ou en erreur) se rouvre d'un clic ; une étape à faire n'est pas cliquable. Réduisez la fenêtre : l'aide disparaît sous 560 px, puis seuls les numéros restent sauf l'étape en cours sous 380 px.

    A — cartes (Alfred)

    Chaque étape dans un cadre. Lourd ; le cadre accent se confond avec le focus.

      B — pastilles et trait recommandée

      Pastille ronde numérotée, trait entre les étapes. Sobre ; en cours monochrome comme le bouton principal.

        C — texte seul

        Fil d'étapes sans pastilles. L'état « fait » ou « erreur » ne se voit plus.

          Vertical (option orientation="vertical")

            4. Menu au clic droit et Popover

            Besoin : AnchoredMenu (menu contre un bouton ou au point du clic droit, avec titre) et AnchoredPanel (volet flottant sans voile). Le menu contre un bouton existe déjà (Menu). On ajoute au Menu l'ouverture à un point et un titre facultatif ; le volet devient le Popover générique que les specs de Menu, Tooltip et Dialog citent déjà.

            A — options du Menu + Popover recommandée

            Menu reçoit anchor (point ou élément), isOpen, onOpenChange, title ; useContextMenu() branche le clic droit et Maj+F10. Popover : volet ancré.

            B — ContextMenu à part

            Nouveau composant qui enveloppe la zone. Double le Menu (même contenu, même clic) : refusé par le brief.

            C — reprise d'Alfred

            AnchoredMenu et AnchoredPanel avec placement maison. Refait ce que React Aria fait déjà (placement, focus, fermeture).

            Essayez dans l'écran réel : clic droit sur une ligne ; « Partager » en haut à droite. Dans le Popover, tapez dans un champ puis cliquez à côté : il rebondit au lieu de se fermer. Échap ferme toujours.
