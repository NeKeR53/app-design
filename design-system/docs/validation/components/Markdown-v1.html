Options comparées



  
1. Dépendances — A retenu
Deux sous-entrées ; react-markdown, remark-gfm et CodeMirror en peer dependencies facultatives. Une app sans Markdown n'installe rien.


import { Markdown } from "socle-ui/markdown";
import { MarkdownEditor } from "socle-ui/markdown-editor";

  
1. Dépendances — B
Dépendances directes, export depuis socle-ui. Simple, mais chaque app installe CodeMirror et react-markdown.

  
1. Dépendances — C
Export depuis socle-ui et import() dynamique. Écarté : le bundler de l'app échoue si le paquet manque.

  
2. Citation — A retenu
Trait de 3 px --line-strong à gauche, texte --fg-2. Ne se confond pas avec un bloc de code.

  
2. Citation — B
Fond --field (Alfred). Trop proche du bloc de code.

  
3. Tableaux — A retenu
Tableau HTML statique au style de Table (en-tête --fs-sm --fg-2, traits --line), qui défile seul. Table est une grille interactive (sélection, tri, clavier en grille) : mauvais rôle pour du texte.

  
4. Police — A retenu
Chasse fixe --font-mono en --fs-sm : listes, tableaux et indentation restent alignés.

  
4. Police — B
Police du texte. Plus proche du rendu, mais tableaux désalignés.

  
5. Retiré (test du générique)
Compte des modifications non enregistrées, Mod+S, remarkPlugins, renderLink : propres à Alfred. La page ou FormPage suit les modifications.
