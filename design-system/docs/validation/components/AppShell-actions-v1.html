AppShell : actions de page dans la barre du haut VALIDÉ le 2026-11-23

Proposition P13. Une action principale à texte dans actions d'AppShell, et un repli en « … » quand la place manque. Validation : par délégation de l'utilisateur, 2026-11-23.

Déjà décidé

  • D-110, D-111 : l'app décrit ses actions par des données ; la zone décide de la forme.
  • D-112 : en topbar, l'action principale à icône reste une icône, en premier.
  • D-117 : sous 640 px, les icônes passent dans « … ».
  • D-021, D-027 : les vues vont dans les onglets ; trop de vues font défiler la rangée.
  • D-157 : la cloche des notifications est dans actions.

Tranché (par délégation)

  1. Forme : option A. Une action principale sans icône devient un bouton à texte plein, tout à droite (D-220).
  2. Repli : selon la place réelle. Les icônes passent dans « … » une à une, depuis la fin ; le bouton à texte passe en dernier, en tête de « … » (D-221).
  3. Priorité : les actions se replient avant les onglets de vues ; la cloche et le bouton du détail ne se replient jamais (D-221).
  4. Slot : actions accepte ActionBar zone="topbar" et des boutons-icônes. Pas de bascule à deux boutons : les vues passent en views (D-222).
Thème Densité Option État Largeur

Les trois options

A — texte si l'action n'a pas d'icône reco

D-112 reste vrai. L'app choisit le texte en omettant l'icône : aucune nouvelle option. La seule différence : une principale sans icône sort de « … ».

B — toujours du texte

Comme les en-têtes. Plus lisible, mais change D-112 pour toutes les apps qui ont déjà une icône principale.

C — icône seulement (actuel)

Rien ne change. L'action attendue reste peu visible ; Alfred garderait une solution locale.

Comportement

  • Ordre : la cloche, puis les actions de la page (icônes, « … », action principale à texte), puis le bouton du détail.
  • La place se mesure en continu. Rien ne bouge tant que tout tient. Aucune animation (D-026).
  • Une icône repliée garde son ordre : elle passe avant les entrées déjà dans « … ». Le texte replié passe en tête.
  • Attente : le bouton à texte montre l'attente (D-116) ; désactivé : opacité 40 %.
  • Un seul bouton plein par écran : si la barre du haut a une action principale à texte, l'en-tête du gabarit n'en a pas.
  • Clavier : Tab passe d'un bouton à l'autre ; « … » s'ouvre avec Entrée, Espace ou flèche bas.
