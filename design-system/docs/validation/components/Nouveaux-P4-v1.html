CodeField (code à usage unique)

K1. Saisie

Option A recommandé

Un seul champ, cases dessinées4 à 8 cases ; un vrai champ caché (autocomplete="one-time-code", clavier numérique) ; le collage remplit tout ; Retour arrière recule ; flèches et Origine/Fin ; onComplete quand c'est plein ; en erreur, le code se vide et le focus revient au début ; « 3 sur 6 » annoncé.
481
React Bits CodeSlots, GOV.UK.

Option B

Un champ par chiffreSix champs séparés. Plus simple à coder, mais le collage et le remplissage automatique marchent mal.
