Recettes de pages et composants manquants VALIDÉ le 2026-11-26

socle-ui 1.21.0 · D-405 à D-416 · choix délégués par l'utilisateur, tranchés selon la recommandation.

Le besoin

Pendant le tournage d'une démo d'Alfred, une page avec un gabarit (ListPage et Drawer) était réussie ; une page sans gabarit (une base documentaire) était improvisée : des PageSection empilées dans une colonne de 760 px. Les recettes donnent à l'agent une page complète de chaque type courant, et les composants qui manquaient pour la faire.

Actuellement / Proposition

Déjà décidé

  • D-018 : l'élément sélectionné va dans le panneau de détail.
  • D-021 : les vues d'une page sont des onglets de la barre du haut.
  • D-111 : une action se décrit par des données ; sa zone fixe sa forme.
  • D-361 : pas de chiffre sans action.
  • D-382 : ChatPage, dépôt de fichiers sur toute la page.
  • D-403 : PageGrid, blocs côte à côte ; D-404 : vue d'ensemble d'abord.

Q1. Recettes : forme, place et zones de chaque recette D-405 à D-410

A · recommandée

Une fiche, des stories et deux captures par recette, livrées dans ai/recipes/ et listées en tête d'AI.md. Zones : vues en onglets, collection ou chat dans main, élément au panneau de détail.

B

Un gabarit de plus par type de page : le socle grossit, chaque page reste à assembler.

C

Des exemples dans la doc de chaque app : chaque app refait les mêmes pages.

Q2. Sources citées d'une réponse D-411

A · recommandée

SourceList : puces numérotées sous la réponse (sources de ChatMessage), passage cité en info-bulle, source ouverte marquée.

B

Une List sous la réponse, une ligne par source.

C

Des liens dans le texte seulement.

Q3. Ouvrir le PDF à la page citée D-412

B

Une méthode impérative appelée par l'app.

C

Q5. Vignettes d'un catalogue ou de documents D-414

A · recommandée

ListPage layout="grid" et thumbnail : états, recherche, filtres, sélection et clavier du gabarit.

B

Des Card dans une PageGrid : ni clavier, ni états de liste.

C

Une liste avec un petit visuel seulement.
