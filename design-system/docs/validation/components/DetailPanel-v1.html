Spec : src/patterns/DetailPanel/DetailPanel.spec.md. Contenu du panneau de détail d'AppShell : sections et lignes de propriété.

Déjà décidé

  • Colonne sur bureau, overlay sur tablette, plein écran sur mobile ; largeur réglable (D-018, D-025).
  • Sections titrées, séparées par un trait ; pas d'ombre (layout-rules).
  • Un réglage s'applique tout de suite (D-007) ; pas d'animation (D-026).
  • Valeur vide : « — » en gris. Pas de champ de saisie dans une ligne.

À décider

  1. Icônes des lignes : A facultatives, alignées par section (si une ligne de la section en a une, les autres gardent la place) ; B jamais ; C obligatoires. Choix : A (D-057). validé
  2. Disposition : A libellé à gauche, valeur à droite ; B deux colonnes alignées (libellé de 96 px, puis valeur) ; C valeur sous le libellé. Choix : B (D-058). validé
  3. Action à droite : une seule par ligne, parmi trois : lien court (un mot), interrupteur, bouton-icône (qui peut ouvrir un menu). Un bouton à texte (« Exporter l'historique ») ne va pas dans la ligne : il va en pied de section, pour laisser la place à la valeur (D-059). validé
  4. Ligne qui s'ouvre (« › ») : dépliage sur place ; ou sous-niveau dans le panneau, avec retour. Choix : sur place (D-060). validé
  5. Sections repliables, état mémorisé. Choix : oui (D-061). validé
