Tooltip — v1 VALIDÉ le 2026-11-21

Spec : src/components/Tooltip/Tooltip.spec.md. Première brique d'AppShell : IconButton, la sidebar et les titres tronqués s'en servent.

Déjà décidé

  • Une info-bulle se place du côté où il y a de la place ; elle n'est jamais coupée par un bord (layout-rules).
  • Fondu de 120 ms ; rien ne bouge si l'utilisateur réduit les animations (D-014).
  • Raccourcis notés « Mod » : ⌘ sur macOS, Ctrl sur Windows (D-006).
  • Texte seul, 240 px de large au plus ; jamais sur un élément désactivé ni sur écran tactile ; contenu interactif → Popover.

À décider

  1. Apparence : A sombre constant (bulle sombre en clair comme en sombre, avec un bord fin en sombre) ; B inversée (claire en mode sombre) ; C flottante comme les menus. Choix : A (D-030). validé
  2. Délai : 500 ms au premier survol ; puis apparition immédiate en passant d'un bouton à l'autre, tant qu'on ne s'arrête pas plus de 600 ms (D-031). validé
  3. Raccourci : affiché après le texte, en couleur secondaire (« Replier la sidebar ⌘B ») (D-032). validé
  4. Flèche vers l'élément : aucune (D-033). validé
