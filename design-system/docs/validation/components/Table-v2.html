Table dense VALIDÉ le 2026-11-23

Besoin d'Alfred (P18) : un tableau dense, comme son DataGrid et son DataTable. Proposition : pas de second composant. Table reçoit des options facultatives. Sans ces options, Table ne change pas. Validation : par délégation de l'utilisateur, 2026-11-23.

Déjà décidé

  • Tableau sans cadre, sur toute la largeur (D-062). Traits horizontaux seulement, pas de zébrage (D-064).
  • Lignes de --row-h : 34 px web, 28 px desktop (D-063).
  • Cases de sélection au survol, toutes visibles dès qu'une est cochée (D-065).
  • Colonnes redimensionnables ; la poignée dessine déjà le séparateur d'en-tête (D-067).
  • La couleur sert seulement aux pastilles de statut (StatusBadge, StatusDot, D-160).

Décidé dans cette page

  • D-270 : options de Table, pas de second composant.
  • D-271 : density="compact" : lignes de 25 px, en-tête de 28 px.
  • D-272 : groupBy : lignes de groupe en texte, avec chevron, repliables (option A).
  • D-273 : rowDescription : lignes doubles, nom et précision dessous.
  • D-274 : une largeur déclarée sous 80 px est respectée.
  • D-275 : en-tête coupé par « … », libellé complet en info-bulle.
  • D-276 : cases teintées écartées : une pastille de statut dans la case.
  • D-277 : menu de case écarté : le menu de ligne suffit.

Ligne de groupe : trois formes

A. Texte et chevron recommandé

Titre en gras, « · n lignes » atténué, petit chevron. Pas de fond : respecte D-064. Le chevron montre qu'on peut replier.

B. Bande teintée

Fond --field sur toute la ligne. Plus visible, mais c'est un fond de ligne, que D-064 écarte.

C. Texte sans chevron (Alfred)

Le plus sobre. Rien n'indique que le clic replie le groupe.
