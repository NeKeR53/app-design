Panneau de détail : largeurs et Agrandir VALIDÉ le 2026-11-23

Proposition P15. Une page choisit la largeur de départ du panneau (sections ou formulaire) ; un bouton Agrandir facultatif l'ouvre en grand. Validation : par délégation de l'utilisateur, 2026-11-23.

Déjà décidé

  • D-018 : colonne sur bureau, overlay sur tablette, plein écran sur mobile.
  • D-025 : poignée de 240 à 480 px, largeur mémorisée, double-clic pour revenir au défaut, flèches par 16 px.
  • D-026 : aucune animation.
  • D-004 : --detail-w suit la densité (300 px web, 272 px desktop).

Tranché (par délégation)

  1. Largeur de départ : option detailWidth d'AppShell, "default" (sections) ou "form" (formulaire, nouveau token --detail-w-form : 460 px web, 420 px desktop). La largeur réglée à la poignée est mémorisée pour chacune (D-240).
  2. Agrandir : option detailExpandable, option A. Bouton bascule dans la barre du haut, juste avant le bouton du détail ; panneau large de 960 px au plus, le contenu garde 360 px (D-241).
  3. Pas de cycle à trois largeurs (Alfred) : deux états, plus prévisibles (D-242).
Thème Densité Contenu Agrandir

Où placer le bouton Agrandir

A — barre du haut, avant le bouton du détail reco

Au-dessus du panneau, à côté du bouton qui l'ouvre. Le panneau garde son dessin : pas d'en-tête ajouté sur bureau.

B — en-tête dans le panneau

Comme Alfred. Il faut ajouter un en-tête au panneau sur bureau (D-018 n'en a pas) : une ligne de plus, partout.

C — double-clic sur la poignée

Rien à voir : personne ne le découvre. D-025 donne déjà au double-clic le retour au défaut.

Exemple d'usage

<AppShell pageTitle="Contacts" detail={<ContactForm />} detailWidth="form" detailExpandable …>

Comportement

  • Agrandir : bouton bascule (aria-pressed), nommé « Agrandir le panneau de détail » ; icône flèches vers l'extérieur, puis vers l'intérieur. Visible sur bureau, quand le panneau est ouvert.
  • Large : 960 px au plus ; le contenu garde au moins 360 px ; la sidebar ne bouge pas. Pas de poignée en mode large. Réduire rend la largeur d'avant.
  • Mémoire : l'état large est mémorisé ; la largeur réglée l'est pour default et pour form, chacune à part. Double-clic : retour au défaut de la page.
  • Tablette et mobile : ni bouton ni mode large (overlay et plein écran, D-018).
  • Aucune animation (D-026).
