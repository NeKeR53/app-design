SearchField — v2 : suggestions et étiquettes REMPLACÉ par la v3

Spec : src/components/SearchField/SearchField.spec.md. Votre demande (D-071) : des suggestions pendant la frappe ; Entrée ajoute une étiquette dans la barre, que l'on retire avec ×.

Déjà décidé

  • Suggestions sous le champ, au style du Menu ; la première est toujours « Rechercher « texte » » : Entrée ajoute donc le texte saisi ; les flèches choisissent une autre suggestion (D-071).
  • × retire une étiquette ; Retour arrière dans un champ vide met en avant la dernière, puis la retire.
  • Échap : ferme les suggestions, puis efface le texte, puis quitte le champ.
  • Suggestions et étiquettes facultatives, désactivées par défaut ; sans elles, c'est un champ simple (D-072).
  • Source locale ou API ; en API, seule la réponse à la dernière saisie s'affiche (D-076). La page simule une API qui répond en 700 ms.
  • Étiquette de 4 px de rayon, car placée dans un autre contrôle (D-040) ; coupée à 160 px.
  • Recherche sans casse ni accents ; compteur en pied ; recherche globale : Mod+K (D-006).

À décider

  1. Apparence : fond --field sans bord ; ou bord fin. Choix : bord fin, nouveau token --line-strong (D-073). validé
  2. Suggestions : A « Rechercher « texte » », puis les valeurs trouvées, rangées par type (Statut, Demandeur, Service), avec le nombre de résultats ; B « Rechercher « texte » », puis les éléments trouvés. Choix : B (D-074). validé
  3. Combinaison des étiquettes de texte : toutes en ET (« remb » ET « hugo » : seulement ce qui contient les deux) ; ou en OU (ce qui contient l'une ou l'autre). Choix : ET (D-075). validé
  4. Débordement : le champ s'élargit jusqu'à 560 px ; au-delà, « +n » résume les étiquettes les plus anciennes (3 restent visibles au focus, 2 sinon) ; un clic sur « +n » les montre toutes ; ou le champ passe toujours sur plusieurs lignes. reco s'élargit
  5. Pendant la frappe, avant Entrée : le texte filtre déjà la liste (aperçu) ; ou seules les étiquettes filtrent. reco aperçu
  6. Raccourci : Mod+F ; « / » ; aucun. reco Mod+F
  7. Surlignage du texte trouvé (nouveau token --mark-bg). reco oui
  8. API : envoi à partir de 2 caractères, après 300 ms sans frappe ; une étiquette ajoutée part tout de suite. reco 2 car. · 300 ms
  9. API : attente montrée à trois endroits : petit indicateur rotatif dans le champ ; ligne « Recherche… » dans les suggestions ; lignes squelettes dans les résultats (les anciens résultats restent visibles si la réponse arrive en moins de 300 ms). reco
  10. API : erreur dans les suggestions, une ligne « Suggestions indisponibles » avec « Réessayer » ; dans les résultats, « Impossible de charger les résultats » avec « Réessayer ». Les étiquettes restent en place. reco
