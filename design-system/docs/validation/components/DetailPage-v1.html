DetailPage et Page — gabarits VALIDÉ le 2026-11-23 — par délégation de l'utilisateur

Specs : src/templates/DetailPage/DetailPage.spec.md et src/templates/Page/Page.spec.md. Décisions D-210 à D-218. DetailPage montre un élément ouvert depuis une liste : retour, titre, statut, méta, actions, puis des sections. Page pose les zones standard quand aucun gabarit ne convient.

Déjà décidé

  • Zones de DetailPage (layout-rules) : header (retour, titre, statut, méta, actions), content (sections titrées séparées par des traits). Les propriétés vont dans le panneau de détail.
  • Actions par Action et ActionBar : zone header (bouton à texte à droite, 3 icônes, « … ») ; zone section dans un titre de section (D-111, D-113).
  • Ouvrir un élément ajoute une vue fermable (D-021). Le nom de la page reste dans la barre du haut.
  • Squelettes après 200 ms (D-165), message d'erreur avec « Réessayer » (D-085), état vide EmptyState (D-166).
  • Aucun bandeau pleine largeur (D-159). Une ombre est réservée à ce qui flotte : on sépare par des traits.

Décisions (par délégation de l'utilisateur)

  1. En-tête fixe, contenu qui défile seul (D-210). retenu
  2. Retour : lien texte « ← Demandes » au-dessus du titre (A), plutôt qu'un bouton-icône (B) ou un fil d'Ariane (C) (D-211). retenu : A
  3. Titre h1 en --fs-xl, statut en StatusBadge juste après, méta sur une ligne séparée par « · » ; titre long à la ligne, jamais tronqué (D-212). retenu
  4. Sections : titre h2 en --fs-lg, description, actions zone section ; trait entre deux sections ; pas de repli (D-213). retenu
  5. Largeur : colonne de lecture de 760 px, centrée, pour DetailPage ; toute la largeur pour Page ; option width (D-214). retenu
  6. États de la page : state = chargement, erreur ou introuvable ; le lien de retour reste visible ; le rechargement passe par l'attente de l'action (D-215). retenu
  7. États d'une section : chargement, erreur, vide compact, dans la section seulement (D-216). retenu
  8. Page composée : barre d'outils (une ligne, contenu libre à gauche, actions zone toolbar à droite), contenu en blocs espacés de 24 px, pied ; pas d'en-tête (D-217). retenu
  9. Page fill : le contenu prend la hauteur sans défiler (éditeur, grand tableau) (D-218). retenu
