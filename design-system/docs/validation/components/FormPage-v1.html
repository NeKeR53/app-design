FormPage et formulaire en modale VALIDÉ le 2026-11-23 — par délégation de l'utilisateur

Deux éléments, une même description des champs : le gabarit FormPage (D-022) pour un long formulaire, et useOpenForm() → openForm(spec) pour une saisie courte en modale. L'app décrit ses champs par des données ; Socle les dessine avec les champs du lot 1 et Dialog. Remplissez, enregistrez, annulez : la scène est jouable.

Déjà décidé

  • FormPage : en-tête (titre, phrase d'intention), sections titrées, pied collé en bas avec l'état d'enregistrement, « Annuler » et l'action principale (D-022).
  • Sur bureau, titre et aide de la section à gauche ; ailleurs, au-dessus (D-022). Points de rupture 640 et 1024 px (D-013).
  • Libellé au-dessus, aide ou erreur en dessous, « (facultatif) » (D-022, D-130). Le champ vérifie seul ; erreur en quittant un champ modifié ou à l'envoi (D-132). Largeurs xs à full (D-133).
  • Pas d'interrupteur pour une valeur qui attend l'envoi : une case (D-137).
  • Modale : « Annuler » puis l'action (D-124) ; Échap ferme, clic hors refusé après une saisie (D-122) ; focus sur le premier champ (D-125) ; attente et erreur sur place (D-128).
  • Messages : pas de bandeau ; un message local reste dans sa zone (D-159).

Tranché le 2026-11-23 (recommandations retenues)

  1. Forme de l'API : A descripteurs de champs (données) ; B composants enfants libres. retenu A (D-190) — deux apps qui décrivent le même formulaire obtiennent le même écran.
  2. Types de champs : text, email, url, tel, password, number, textarea, select, combobox, radio, checkbox, checkboxGroup, et le groupe fieldset. Pas de switch (D-137), pas de date tant que Socle n'a pas de sélecteur, pas de champ libre. retenu (D-190)
  3. Champs courts : A chacun sur sa ligne, à sa largeur ; B deux champs courts consécutifs partagent une ligne. retenu A (D-191) — ordre de lecture et de tabulation sans surprise ; un groupe qui va ensemble passe par fieldset.
  4. État d'enregistrement : A une phrase à gauche du pied (« Modifications non enregistrées », « Enregistrement… », « Enregistré », l'erreur en rouge) ; B une pastille seule ; C rien. retenu A (D-194)
  5. « Annuler » après une saisie (FormPage) : A confirmation « Abandonner les modifications ? » ; B quitter tout de suite. retenu A (D-195) — un long formulaire perdu coûte cher. La modale garde D-122 (saisie courte).
  6. Action principale : A toujours active ; B grisée tant que rien ne change. retenu A (D-196) — un bouton grisé n'explique rien ; l'envoi montre les erreurs. Mod+Entrée envoie, même depuis une zone de texte.
  7. Échec de l'envoi : A erreurs sous les champs et phrase sur place (pied de la page, au-dessus du pied de la modale) ; B toast. retenu A (D-192, D-198) — l'erreur reste à côté de ce qu'il faut corriger (D-159).
  8. Résultat de openForm : A promesse des valeurs, ou null si annulé ; avec onSubmit, la modale attend et reste ouverte en cas d'échec ; B true/false (Alfred). retenu A (D-197)
  9. Taille de la modale : A automatique, sm jusqu'à quatre champs sans zone de texte, sinon md ; B toujours md. retenu A (D-198) ; six champs au plus, au-delà une FormPage.

Exemple d'usage

import { FormPage, useOpenForm, type FormSection, type FormField } from "socle-ui";

const sections: FormSection[] = [
  { title: "Général", description: "Ce qui identifie le projet dans les listes.", fields: [
    { type: "text", name: "name", label: "Nom", isRequired: true, description: "Visible par toute l'équipe." },
    { type: "select", name: "state", label: "État", isRequired: true, width: "md",
      options: [{ id: "todo", label: "À faire" }, { id: "doing", label: "En cours" }] },
    { type: "number", name: "budget", label: "Budget", description: "En euros." },
  ]},
  { title: "Détails", fields: [
    { type: "textarea", name: "description", label: "Description" },
    { type: "checkbox", name: "notify", label: "Prévenir l'équipe" },
  ]},
];

<FormPage title="Nouveau projet" description="Décrivez le projet."
  sections={sections} submitLabel="Créer"
  onSubmit={async (values) => { await api.create(values); navigate("/projets"); }}
  onCancel={() => navigate("/projets")} />

const openForm = useOpenForm();
const values = await openForm({
  title: "Nouveau contact", submitLabel: "Ajouter",
  fields: [{ type: "text", name: "name", label: "Nom", isRequired: true },
           { type: "email", name: "email", label: "Adresse e-mail", isRequired: true }],
  onSubmit: (v) => api.addContact(v),   // facultatif : attente et erreur sur place
});
if (values) notify({ title: "Contact ajouté", tone: "success" });
