Grille (docs/checklist.md)

  • États : chargement (Skeleton dans la tuile, nommé « Chargement de <alt> ») ; prête ; erreur (« Image indisponible », « Réessayer » si l'image vient d'une adresse ou si l'app donne onRetry) ; survol (bord --line-strong) ; focus (anneau commun).
  • Clavier : Tab atteint chaque vignette, puis « + N » ; Entrée ou Espace ouvre ; dans la vue agrandie, ← → parcourent (sauf dans un champ, ou si l'image zoomée défile en largeur) ; Échap ferme et rend le focus à la vignette.
  • Densité : mêmes tailles dans les deux densités ; la barre et le pied suivent --bar-h et --icon-btn.
  • Taille d'écran : max-width: 100% ; sur mobile, la modale xl passe en plein écran (D-121).
  • Niveau de réglage : formes verrouillées (pas de largeur, de rapport ni de recadrage libres) ; nombre de vignettes visibles réglable (visible).
  • Accessibilité : vignette = bouton « Agrandir <alt> », image alt ; galerie = ul nommée ; « + N » nommé « Voir N autres images de <groupe> » ; position aria-live.
