Spec : src/components/IconButton/IconButton.spec.md. Deuxième brique d'AppShell, après Tooltip (validé).

Déjà décidé

  • label obligatoire : nom accessible et texte de l'info-bulle ; raccourci facultatif (D-032).
  • Info-bulle sombre, 500 ms, sans flèche (D-030 à D-033) ; aucune sur un bouton désactivé.
  • Icône de 16 px en currentColor (D-011, D-028) ; boutons voisins espacés de 2 px.
  • Pas de couleur d'accent ni de danger ; pas de chargement ; bascule possible (aria-pressed).
  • Sélectionné : fond clair --hover ; au survol, il fonce en --selected (D-034).
  • Sur écran tactile : zone de 44 × 44 px, pas d'info-bulle.

À décider

  1. Taille : A 28 px en web, 24 px en desktop ; B 32 px en web, 28 px en desktop. Les deux passent le minimum de 24 px. Choix : A (D-035). validé
  2. Rayon : arrondi de 8 px (--radius-md), comme les éléments de la sidebar ; ou rond. Choix : 8 px (D-036). validé
  3. Variantes : une seule, transparente ; ou aussi une variante avec fond --field pour un bouton isolé sur une image ou une carte (coin de la carte ci-dessous). Choix : une seule (D-037). validé
