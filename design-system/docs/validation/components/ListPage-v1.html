ListPage et valeurs typées VALIDÉ le 2026-11-23

Mode propose, besoin venu d'Alfred (proposition P8, qui remplace CollectionPage, PageToolbar, Pagination et FormattedValue). Gabarit déclaratif : l'app passe des données ; le gabarit dessine tout. Tout est nouveau : version mineure. Validation par délégation de l'utilisateur : chaque point retient la recommandation.

Déjà décidé

  • Zones du gabarit : header, actions, toolbar, list, footer, empty (layout-rules).
  • Actions par le modèle Action : zone header en tête, row sur les lignes, empty dans l'état vide (D-110 à D-114).
  • Recherche : 2 caractères, sans casse ni accents, texte trouvé en gras (D-080, D-087).
  • Chargement en squelettes, puis barre fine ; erreur en message centré ou bandeau ; « Aucun résultat pour … » (D-084 à D-086).
  • Vues de la page dans les onglets, pas dans la barre (D-021). Pas de bandeau pleine largeur (D-159).
  • Statut : point et libellé (D-160) ; vide en EmptyState (D-166) ; lien souligné (D-167).

À décider

  1. API : A déclarative (données, colonnes typées, filtres, Action) ; B zones libres en ReactNode. validé : A (D-173)
  2. Valeurs typées : seize types au format français ; vide « — » ; illisible en texte brut ; le type fixe alignement, largeur et tri. validé (D-170 à D-172)
  3. Recherche et filtres : dans la barre ; locaux par défaut, remote pour une API. validé (D-174)
  4. Pied : A « Afficher plus » par défaut, B pagination en option, C défilement infini. validé : A, B en option (D-175)
  5. Vide et aucun résultat : vide sans barre ni pied ; « Effacer la recherche » vide aussi les filtres. validé (D-176)
  6. Mémoire : filtres et tri mémorisés, recherche oubliée. validé (D-177)
  7. Sélection multiple : la barre d'outils devient la barre de sélection. validé (D-178)
