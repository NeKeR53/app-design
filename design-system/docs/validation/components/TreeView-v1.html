Cette action est définitive.

À jouer : clic (sélection), Mod+clic et Maj+clic (choix multiple), double-clic (ouvrir ou déplier), chevron (déplier sans sélectionner). Clavier : flèches, Droite et Gauche, Origine et Fin, Entrée, une lettre (recherche par frappe), Maj+F10 (menu). Glissez une ligne sur une autre : haut de la ligne = avant, milieu = dans (dossier seulement), bas = après.

Règle : la navigation de l'app va dans la Sidebar, même si elle est hiérarchique. Un arbre de données va dans une TreeView, jamais dans la Sidebar. Les deux ne partagent aucun code de rendu ; ils partagent les tokens et React Aria Tree.

4. Ce qui ne se joue pas ici

  • Lecteur d'écran : rôle tree, aria-level, aria-expanded, aria-selected, aria-busy pendant le chargement (React Aria).
  • Glisser-déposer au clavier : un bouton « Déplacer » invisible, atteint au lecteur d'écran (React Aria).
  • Écran tactile : appui long sur la ligne pour le menu « … ».
