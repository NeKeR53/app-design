Page : dépôt de fichiers sur toute la page VALIDÉ le 2026-11-26 (par délégation de l'utilisateur)

Besoin (app desktop Alfred) : une page composée sur le gabarit Page reçoit des fichiers glissés depuis le système : un relevé à importer dans un tableau de bord, une image à ouvrir dans un éditeur, des pièces pour une synthèse. ChatPage (D-382) et ListPage (D-416) montrent un cadre « Déposez… » sur toute la page ; Page n'en a pas. L'app ne peut pas en dessiner un (pas de HTML stylé, D-217) : elle mettait un bloc FileUpload dans la page, ce que la règle « Vue d'ensemble d'abord » écarte (D-404).

Test du générique : toute app dont une page composée reçoit des fichiers (web : dépôt du navigateur ; desktop : dépôt capté par le système, Tauri). Rien de métier.

Déposez les fichiers pour les ajouter

Options facultatives onDropFiles, isDraggingFiles, dropLabel, comme ListPage. Sans elles, rien ne change (version mineure 1.22.0).

Déjà décidé

  • D-382 : ChatPage porte la zone de dépôt de toute la page ; isDraggingFiles montre le cadre quand le système capte le glisser.
  • D-416 : ListPage, même cadre, code partagé (lib/fileDrop), « Déposez les fichiers pour les ajouter » ; pas de zone dessinée dans la page.
  • D-404 : une action (importer, ajouter) est une Action de la barre, jamais un bloc à elle seule.
  • D-217 : Page pose ses zones ; l'app n'y met pas de HTML stylé.

À décider

Q1. Où se pose le cadre ?

A. Sur toute la page recommandé
Barre d'outils, contenu et pied, à 12 px des bords, comme ListPage : on dépose où l'on est, la page entière est la cible.
B. Sous la barre d'outils
Contenu et pied seulement, comme ChatPage : la barre reste lisible pendant le glisser.
Autre
Précisez dans la conversation.

Raison de A : la barre d'une Page porte des filtres et des actions qu'on ne touche pas pendant un glisser ; un cadre plein rappelle celui de ListPage, qu'on voit dans la même app.

Q2. Texte par défaut du cadre

A. « Déposez les fichiers pour les ajouter » recommandé
Le texte de ListPage ; l'app le précise avec dropLabel (« Déposez le relevé pour l'importer »).
B. « Déposez les fichiers ici »
Plus neutre, mais ne dit pas ce qui se passe.
