Ce qui ne se joue pas ici

  • Diff de plusieurs fichiers (option patch) : un en-tête de fichier collant par fichier, avec statut (« Ajouté », « Supprimé », « Renommé ») et DiffStat.
  • Gros fichiers : seules les rangées visibles sont dessinées ; hauteur de rangée fixe de 20 px dans les deux densités.
  • Mode contraste élevé : mots retirés barrés, mots ajoutés soulignés, signes en gras.
  • Lecteur d'écran : chaque ligne changée commence par « Ajoutée : » ou « Retirée : » ; le changement courant est annoncé (« Changement 2 sur 3 : avant, ligne 7 ; après, lignes 7 à 8 »).
