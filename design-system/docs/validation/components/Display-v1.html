Petits éléments d'affichage VALIDÉ le 2026-11-23

Mode propose, besoin venu d'Alfred (proposition P7). Neuf composants génériques : StatusBadge, StatusDot, Avatar, ProgressBar, Skeleton, EmptyState, Link, Code, Divider. Toutes les options sont facultatives ; version mineure. List, Table et Sidebar dessinent déjà un statut, un avatar et des squelettes : ces composants reprennent ce dessin, et List, Table et Sidebar les utilisent ensuite (pas de doublon).

Déjà décidé

  • Monochrome : la couleur ne porte que du sens ; succès, alerte, erreur et info ont leur couleur (principes).
  • Statut dans List : point de 7 px et libellé en --fs-xs, --fg-2 (List.spec, D-044). Tons : neutre, info, succès, alerte, erreur.
  • Non-lu : point accent, à la place du statut (D-044). Il reste un usage à part, pas un ton de statut.
  • Avatar : 24 px dans le compte de la sidebar, 32 px dans List (D-069), initiales sur fond neutre.
  • Squelettes de List et Table : barres de 10 px en --field, rayon 4 px, sans animation (D-084, D-026).
  • Barre de chargement indéterminée : 2 px accent, fixe si l'utilisateur réduit les animations (D-084).
  • « Aucun résultat » (D-086) se distingue de l'état vide du gabarit : icône, titre, phrase, action principale (layout-rules, ListPage empty).
  • Rayons : 4, 8 ou 12 px seulement (D-040). Libellés internes par le dictionnaire messages (D-089).
  • L'action principale d'EmptyState est un emplacement : elle recevra le Button de P1.

À décider

  1. StatusBadge, dessin : A point + libellé, sans fond (dessin actuel de List) ; B pastille neutre --field avec point ; C pastille teintée par ton (Alfred). validé : A
  2. Ton « en attente » : ajouter un sixième ton pending, point creux, pour ce qui n'a pas commencé ? validé : oui
  3. StatusDot seul : point sans libellé visible, mais avec un nom accessible obligatoire et une info-bulle ; ou point toujours décoratif, à côté d'un texte. validé : nom obligatoire
  4. Avatar : A fond neutre pour tous ; B fond teinté calculé à partir du nom. Tailles 24 / 32 / 40 px. validé : A
  5. ProgressBar : A barre de 4 px ; B barre de 6 px. Remplissage accent ; ton alerte ou erreur facultatif ; mode indéterminé. validé : A
  6. Skeleton : A fixe, comme aujourd'hui ; B pulsation douce (coupée si animations réduites). Formes : ligne, cercle, bloc. validé : A
  7. EmptyState : A icône de 32 px en --fg-3, seule ; B icône de 22 px dans un cercle --field de 48 px. Taille compacte sans icône pour les panneaux. validé : A
  8. Link : A toujours souligné ; B souligné au survol seulement. validé : A
  9. Code : A fond --field et rayon 4 px ; B chasse fixe seule, sans fond. Bloc : fond --field, rayon 8 px, défile, joignable au clavier. validé : A
  10. Reprise dans List, Table, Sidebar : ces composants utilisent StatusBadge, Avatar, Skeleton et EmptyState, sans changer de rendu. validé : oui
