Tous les outils restent dans un groupe. L'objet s'ouvre d'un clic ; les images sont sous la sortie ; « Arrêté » a sa place.

Q1 — Objet cliquable

Ouvrir le fichier lu ou modifié depuis la ligne.

A · onObjectPress recommandé

L'objet devient un Link (D-167) en chasse fixe. Avec une sortie, la ligne garde un chevron, bouton à part (24 px), juste après le texte.

Lu src/dates.ts

Un fichier local s'ouvre par l'app (Tauri, éditeur) : une fonction suffit, pas d'URL.

B · objectHref

L'objet est un lien vers une adresse. Ne couvre pas l'ouverture d'un fichier local par l'app.

Lu src/dates.ts

C · Toute la ligne ouvre le fichier

La ligne entière est le lien ; la sortie de l'outil n'est plus atteignable.

Lu src/dates.ts

A · attachments: ReactNode recommandé

Emplacement facultatif, sous le texte de detail, dans la sortie ouverte. La ligne s'ouvre dès qu'il y a une pièce. L'app y pose les vignettes (D-383) ou des AttachmentChip.

Q3 — État « Arrêté »

Outil interrompu par l'utilisateur ou par l'agent.

A · status: "stopped", neutre recommandé

Icône du type, « Arrêté » visible en --fg-3. Résumé : « · 1 arrêté ». Groupe replié : seuls les échecs restent visibles.

Comme « Terminé » : l'arrêt ne se voit pas.
