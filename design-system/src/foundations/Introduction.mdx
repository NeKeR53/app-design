# Socle

Design system partagé par les apps web et desktop (Tauri).

- **Mode** et **densité** : utilisez les sélecteurs de la barre d'outils.
- **Règles** : principes, mise en page (« où va une information ») et journal des décisions.
- **Dans une app** : `import "socle-ui/styles.css"`, puis `import { … } from "socle-ui"`. Avec Tailwind : `@import "socle-ui/theme.css"`.
